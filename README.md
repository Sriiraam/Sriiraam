## About Me

I build **reproducible bioinformatics pipelines and analytical systems** for modern genomics and next-generation sequencing applications.

My work spans **transcriptomics, immunogenomics, single-cell genomics, clinical genomics, and long-read sequencing**, with an engineering focus on:

**Workflow orchestration • Reproducibility • Containerization • Validation • Benchmarking • CI/CD • Interactive reporting**

I focus on transforming biological analyses into **structured, reproducible, validated, and maintainable computational workflows**.
