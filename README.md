## 🧬 About Me

I build **reproducible bioinformatics pipelines and analytical systems** for modern genomics and NGS applications.

My work spans:

**Transcriptomics • Immunogenomics • Single-cell Genomics • Clinical Genomics • Long-read Genomics**

with an engineering focus on:

**Workflow orchestration • Reproducibility • Containerization • Validation • Benchmarking • CI/CD • Interactive reporting**

I focus on transforming biological analyses into **structured, reproducible and maintainable computational workflows**.
